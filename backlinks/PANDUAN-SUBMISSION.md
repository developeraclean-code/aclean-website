## CARA PUBLISH DI MEDIUM

1. Buka medium.com → Login (buat akun gratis jika belum punya)
2. Klik "Write a story"
3. Copy-paste konten dari file `.md` di folder `medium/`
4. Tambahkan tag: `service-ac`, `tangerang`, `ac-maintenance`, `indonesia`
5. Publish → pilih "Publish Now"
6. Setelah publish, share link ke Twitter/Facebook untuk sinyal sosial

**Akun Medium yang disarankan:**
- Gunakan nama akun profesional: "AClean Service" atau "Tips Servis AC"
- Upload foto profil logo AClean
- Isi bio: "Jasa service AC profesional di Tangerang Selatan | aclean.id"

---

## CARA PUBLISH DI LINKEDIN

1. Buka linkedin.com → Login
2. Klik "Write an article" (bukan "Post")
3. Copy-paste konten dari file `.md` di folder `linkedin/`
4. Tambahkan gambar cover (gunakan foto teknisi)
5. Publish

**Tip:** Publish dari akun pribadi pemilik bisnis, bukan akun perusahaan — artikel personal dapat engagement lebih tinggi.

---

## CARA SUBMIT KE DIREKTORI

Ikuti panduan per direktori di file `backlinks/directories/DIREKTORI-MASTER.md`.
Setiap entry sudah berisi: URL form, field yang diisi, dan teks yang digunakan.

---

## TRACKING BACKLINK

Setelah semua submit, cek backlink dengan tool gratis:
- **Google Search Console** → Links → External links
- **Ahrefs Free** (ahrefs.com/backlink-checker) — masukkan aclean.id
- **Moz Link Explorer** (moz.com/link-explorer)

Target 3 bulan setelah submission:
- Domain Rating naik dari ~15 ke ~25
- Jumlah referring domains: 25+
- Ranking keyword "service AC [area]" masuk halaman 1
